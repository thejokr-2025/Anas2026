## كيف تحصل على ملف APK (بدون تركيب أي برنامج)

### الخطوات

**1) ارفع المشروع على GitHub**
- ادخل حسابك `thejokr-2025` على github.com
- افتح مستودع `Anas` (أو أنشئ مستودعاً جديداً)
- اضغط **Add file** ← **Upload files**
- اسحب **كل محتويات هذا المجلد** وأفلتها
  (مهم: ارفع المحتويات نفسها، لا المجلد الخارجي)
- اضغط **Commit changes**

**2) شغّل البناء**
- اضغط تبويب **Actions** في أعلى الصفحة
- إن ظهرت رسالة تفعيل، اضغط الزر الأخضر للموافقة
- سيبدأ البناء تلقائياً باسم "بناء تطبيق APK"

**3) حمّل الـ APK**
- انتظر حتى تظهر علامة ✓ خضراء (حوالي 5 دقائق)
- اضغط على البناء المكتمل
- في الأسفل تحت **Artifacts** حمّل `AnasArchive-APK`
- فك الضغط ← ستجد `app-debug.apk`

**4) ثبّت على الهاتف**
- انقل الملف للهاتف وافتحه
- فعّل "السماح بالتثبيت من مصادر غير معروفة" إن طُلب

## المميزات

- تصنيف الجهات: عميل / تاجر / بنك / أخرى — تبويبات عمودية والأسماء تحتها
- أنواع المستندات: فاتورة / سند قبض / سند صرف / إشعار / مردود / أخرى
- إرفاق **عدة صور وملفات دفعة واحدة** + التقاط بالكاميرا
- **دمج كل مرفقات الشخص في PDF واحد** ومشاركته عبر واتساب/بلوتوث/درايف/أي تطبيق
- **طباعة حقيقية** عبر خدمة الطباعة الرسمية في أندرويد
- تقارير حسب النوع الأساسي (بدون تواريخ) مع تصدير PDF
- نسخ احتياطي واستعادة عبر مدير الملفات الحقيقي
- عربي / إنجليزي — فاتح / داكن
- ألوان كبدية عنابية وأزرار كبيرة
- يعمل بالكامل بدون إنترنت

## التقنيات

- Kotlin + Jetpack Compose (Material 3)
- Room للتخزين المحلي
- iText 7 لدمج PDF
- DataStore للإعدادات
- Coil لعرض الصور
